# 부부 예금 · 양도소득세 연계 사이트

GitHub Pages용 정적 사이트입니다. ZIP에 있는 파일 전체를 같은 저장소 최상위 폴더에 올리세요.

- index.html: 전체 현황, 세금 연계액 요약
- deposit.html / deposit.js: 예금 3안 비교, 단기 1억 원과 부부별 세금 자동 비교
- tax.html / tax.js: 양도세 참고 계산, 실제 국세·지방세 납부액 4개 입력
- common.js: 같은 브라우저 내 저장 및 연계
- style.css: 밝은 반응형 디자인

## 사용 순서

1. 양도세 페이지에서 양도가액, 취득가액 등을 넣고 과세 여부를 고르면 참고 추정액이 예금 페이지에 표시됩니다. 참고 추정액은 확정 납부액이 아닙니다.
2. 홈택스·위택스 실제 금액을 확인한 후 양도세 페이지의 실제 납부액에 남편 국세, 남편 지방세, 아내 국세, 아내 지방세를 각각 입력합니다. 0원도 확인된 경우만 입력하세요.
3. 네 금액을 확인했다는 체크를 누르면 예금 운용 페이지에서 부부 각 5,000만 원의 단기 준비금과 각각 비교합니다. 첫 화면에도 연계됩니다.
4. 실제 납부액을 다시 수정하면 확정 체크가 자동 해제됩니다. 예금 원금이나 이체는 절대 자동으로 변경되지 않습니다.

## 주의 사항

- 동기화는 같은 사이트의 같은 브라우저/기기에서만 작동합니다. PC·휴대폰 간 자동 동기화되지 않습니다.
- 입력한 데이터는 브라우저 localStorage에만 저장됩니다. GitHub 저장소나 별도 서버로 업로드하지 않습니다.
- 세액 산식은 단순 참고용입니다. 비과세 및 최종 납부액은 공식 신고 자료로 확인하세요.
- 기존 저장 키(couple-money-v4:)를 유지해 이전 예금 설정·체크리스트를 보존합니다.

## 실제 지출액 선택 입력 (2026-11-22 추가)

양도세 페이지의 `STEP 1 · 금액`에서 다음 비용을 기억용으로 표시합니다. **기본값은 모두 미선택**입니다. 체크한 항목만 `기타 필요경비` 입력액과 합산하며 양도차익/참고 추정세액 및 예금 화면의 참고 금액에 연계됩니다.

- 취득세 14,794,450원: 납부증빙 확인 후 선택
- 매수·매도 중개보수 합계 5,000,000원: 영수증/계좌이체증빙 확인 후 선택
- 라돈 검출로 필요해 시행한 보수 1,300,000원: 일반 수선인지 자본적 지출인지 공사내역 판단 후 선택
- 천장 고정형 시스템에어컨 5,700,000원: 냉난방 설비 설치의 자본적 지출 해당 여부와 품목/설치비 내역 확인 후 선택

항목별 금액과 선택 여부는 같은 브라우저에 보관됩니다. 공제 여부는 자동 판정하지 않습니다. 취득가액 또는 홈택스 자동조회 금액과 **중복 반영 금지**. 참고 추정세액이 바뀌어도 `실제 신고·납부액`으로 확정 체크한 숫자는 사용자가 직접 변경해야 합니다.
